Giải nén code vào thư mục htdocs (đối với Xampp hay Apache) hoặc www (đối với Wampp, nginx, docker).

Truy cập vào phpmyadmin, tạo database mới tên là perfumeshopdb, sau khi tạo xong, import file perfumeshopdb.sql  trong thư mục database/ để tạo bảng và dữ liệu.


Cấu hình các thông số kết nối SQL trong file connection.php cho phù hợp

$servername = "localhost";

$username = "root";

$password = "";

$database = "perfumeshopdb";

Gõ đường dẫn http://localhost/thư_mục_chứa_code để chạy ứng dụng web
